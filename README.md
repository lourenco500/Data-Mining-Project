# Data-Mining-Project
In this project, we acted as consultants for Amazing International Airlines Inc. (AIAI). Our task was to analyze customer loyalty membership data and corresponding flight activity collected over a three-year period with the objective of developing a **data-driven segmentation strategy**.

This included targeted marketing actions, loyalty optimization and improved resource allocation. Through an end-to-end **clustering approach**, the analysis identifies a set of distinct customer segments that reflect systematic differences in customer value, engagement intensity and seasonal travel behavior.
